# P1 — Flutter Environment Setup & First App

## 1. Install Flutter SDK and Dart

### Steps:

1. Download and install the **Flutter SDK**.
    
2. Extract Flutter to a suitable location.
    
3. Add the Flutter `bin` folder to the system **PATH**.
    
4. Open Terminal/Command Prompt.
    
5. Check the installation using:
    

```bash
flutter --version
```

6. Check the Flutter environment and required dependencies using:
    

```bash
flutter doctor
```

Flutter includes the **Dart SDK**, so Dart is available with Flutter.

---

## 2. Configure Android Studio / VS Code

### Android Studio

1. Install **Android Studio**.
    
2. Install the **Flutter plugin** from Plugins.
    
3. The Dart plugin is installed/configured along with Flutter support.
    
4. Install/configure the Android SDK and emulator.
    
5. Create an Android Virtual Device (AVD).
    
6. Run:
    

```bash
flutter doctor
```

to check whether the required setup is complete.

### VS Code

1. Install **Visual Studio Code**.
    
2. Open Extensions.
    
3. Install the **Flutter extension**.
    
4. This provides Flutter/Dart development support.
    
5. Open the Flutter project in VS Code.
    
6. Select an emulator or connected physical device.
    
7. Run the application.
    

---

## 3. Create a Hello World Flutter App

Create a Flutter project using:

```bash
flutter create hello_world
```

Go into the project:

```bash
cd hello_world
```

Run the project:

```bash
flutter run
```

### Basic Hello World Code

Replace the contents of `lib/main.dart` with:

```dart
import 'package:flutter/material.dart';

void main() {
  runApp(const MyApp());
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      home: Scaffold(
        appBar: AppBar(
          title: const Text('Hello World'),
        ),
        body: const Center(
          child: Text('Hello World'),
        ),
      ),
    );
  }
}
```

### Important structure

```text
main()
   ↓
runApp()
   ↓
MyApp
   ↓
MaterialApp
   ↓
Scaffold
   ↓
AppBar + Center + Text
```

---

## 4. Run on an Emulator

### Android Emulator

1. Open Android Studio.
    
2. Open **Device Manager**.
    
3. Create/start an Android Virtual Device.
    
4. Start the emulator.
    
5. Open the Flutter project.
    
6. Run:
    

```bash
flutter run
```

The Hello World application will run on the Android emulator.

---

## 5. Run on a Physical Device

### Android Phone

1. Enable **Developer Options** on the Android phone.
    
2. Enable **USB Debugging**.
    
3. Connect the phone to the computer using a USB cable.
    
4. Allow the computer to access/debug the device when prompted.
    
5. Check that Flutter detects the device:
    

```bash
flutter devices
```

6. Run the application:
    

```bash
flutter run
```

The Flutter app will then run on the connected physical device.

# Short Exam Answer

**Flutter environment setup involves installing the Flutter SDK, configuring the Android SDK and development environment, and verifying the setup using `flutter doctor`. Android Studio or VS Code can be configured with Flutter/Dart support. A new Flutter application can be created using `flutter create hello_world`. The application contains `main()`, `runApp()`, `MaterialApp`, `Scaffold`, and a `Text` widget displaying "Hello World". The application can be executed on an Android emulator or a physical device using `flutter run`.**
